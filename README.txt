MY SURPRISE WEBSITE ❤️

Folder structure:
my-surprise/
├── index.html
├── style.css
├── script.js
└── images/
    └── photo1.jpg

1. Put your photo inside the images folder.
2. Name it photo1.jpg
3. Open index.html in a browser.

To customize:
- Change "Bambi" in index.html
- Change the letter in script.js (const message)
- Add more photos later if you want.
